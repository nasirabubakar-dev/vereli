# VERELI — Modern Restaurant Website Demo

VERELI is a modern, responsive restaurant website concept created to demonstrate the quality, design, and development capabilities that can be delivered for real restaurants and hospitality businesses.

The project represents the type of polished website that can be customized and developed for a real client.

> **VERELI is a fictional demo restaurant brand and is not a website built for an actual client.**

---

## ✨ Overview

VERELI was designed as a premium restaurant experience with a warm visual identity, responsive layouts, reusable React components, menu browsing, cart functionality, and WhatsApp ordering.

The goal is simple:

**Show potential clients what their own modern restaurant website could look and feel like.**

The design can be adapted by replacing the branding, content, imagery, menu, contact information, and business requirements.

VERELI is designed to provide a consistent experience across different screen sizes.

The layout adapts to:

**Desktop → Tablet → Mobile**

---

## 🧩 Architecture

VERELI uses a component-based React architecture with shared cart state managed through React Context.

The project separates:

- Reusable UI components
- Page components
- Shared cart state
- Restaurant data
- Custom hooks
- Global and page-specific styles

Restaurant content is centralized in `data.js`, while reusable behavior such as document titles and reveal animations lives in custom hooks.

## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm

Check your versions:

```bash
node -v
npm -v
```

### Installation

```bash
git clone https://github.com/nasirabubakar-dev/vereli.git
cd vereli
npm install
```

Start the development server:

```bash
npm run dev
```

---
